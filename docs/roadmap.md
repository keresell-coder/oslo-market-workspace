# Roadmap

## Product Direction

Build an Oslo Bors screening workspace where Watchlist is the synthesis view and
all outputs remain descriptive, source-aware, and screening-grade.

Current release direction: **Beta v0.1.0 as a static GitHub Pages dashboard**
generated by scheduled/manual GitHub Actions. The local Python app remains the
development and private-use backend, but the preferred public beta path is
static Pages.

## Non-Negotiables

- No buy/sell investment advice.
- No standalone cheap/expensive/fair/neutral valuation labels.
- Missing data stays missing.
- Free data is screening-grade only; source, timestamp/freshness, confidence,
  limitations, and errors must remain visible.
- Relative valuation requires peer, sector, own-history, source-quality, and
  missing-data context.
- Do not edit Oslo Screener repos unless the user explicitly asks.
- Keep local `/api/*` mode and static `docs/data/*.json` mode working.

## Verification Baseline

For app/code changes:

```bash
python3 -m py_compile app/server.py scripts/build_static_site_data.py
node --check app/static/app.js
node --check docs/app.js
```

For static data changes:

```bash
python3 scripts/build_static_site_data.py
python3 -m json.tool docs/data/manifest.json
python3 -m json.tool docs/data/watchlist-overview.json
python3 -m json.tool docs/data/technical-indicators-watchlist.json
```

For local server checks when running:

```bash
curl -s http://127.0.0.1:8765/api/watchlist-overview | python3 -m json.tool
curl -s "http://127.0.0.1:8765/api/fundamentals?symbols=MOWI.OL" | python3 -m json.tool
curl -s "http://127.0.0.1:8765/api/technical-indicators?universe=watchlist" | python3 -m json.tool
curl -s "http://127.0.0.1:8765/api/event-monitoring" | python3 -m json.tool
```

For user-visible updates:

```bash
scripts/open_in_safari.sh
```

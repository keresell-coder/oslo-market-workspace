# Selected primary financial ingestion — review batch 2

This batch adds immutable, separately labelled issuer facts before any formula
changes. It starts at generated main d295ac610882219815c5f6128e1cbb45075c4aff.
No production output is regenerated by this PR, and merge/deploy awaits review.

## What is ingested

`data/primary/NOD.OL.json` has 64 selected field/period records, plus nine explicit
TTM bridges, transcribed from Nordic's original unaudited Q3 2026 report printed
pages 14–17. Each record identifies issuer, statement/table/row/page, period and
scope, group basis, currency, scale, value and transcription-review state. Each
source has publication date, issuer URL and full original SHA-256. The report is
published 22 October; current accounting period ends 30 September. The package's
original network retrieval has only a date; the exact timestamp records local
artifact receipt and is explicitly not claimed as original network retrieval.

The original source PDF is committed under its hash in `data/primary/artifacts/`.
Only this report is active, rather than the entire research package. Its direct
issuer URL returned HTTP403 during implementation; the independently supplied
Library original was hash-verified and visually checked. Committing this one
necessary source makes the selected facts reproducible without browser credentials
or an unreliable scheduled download. Runtime always checks the artifact hash;
changed/missing sources block the configured primary input, never silently pass.

CFO10.095m. September assets1,087.838m, equity734.346m and cash266.795m.

net income58.174m and CFO39.938m. Quarterly and cumulative amounts stay separate.

## Output boundary

Workspace adds `primaryFinancials` beside unchanged provider `quarterlyStatements`.
The primary detail panel shows current quarter/stock values and explicit TTM
bridges. Comparisons preserve the provider field/value or explicit non-comparability,
difference and reason. This PR does not substitute primary facts into provider
EPS, multiples or source-gate history. Nordic valuation multiples therefore remain
withheld; ingested primary facts are not a claim that an EPS/EV ratio is validated.
Existing historical snapshots are not reloaded from newly known primary ledgers.

`data/reconciliation/DOFG_definition_component_mapping.json` is audit-only:
issuer IFRS EBITDA332m, management gross-JV EBITDA358m and provider347m have
separate definitions. The gross-financial-cost reconstruction is numerically
consistent, not confirmation of Yahoo methodology. Provider TTM923m, IFRS TTM874m
and the EV bridge remain separate/unresolved. EV metrics stay withheld; no
illustrative EV or ratio is published as a corrected valuation.

MOWI's selected annual control/proxy notes are retained separately; no MOWI ledger,
provider series or formula changes. PUBLI's incomplete historical SEK restatement
is deferred: no spot-conversion or mixed numerator/denominator substitutions.

## Validation and review evidence

The primary engine rejects wrong issuer, currency, unit, consolidation scope,
duplicate identities, future chronology, invalid/cumulative quarter scopes,
non-additive TTM bridges, unknown sources, changed hashes and unavailable sources.
The current guard suite remains intact. `scripts/preview_primary_ingestion.py`
reproduces `docs/review-evidence/primary-ingestion/nod-before-after.json` offline.
It uses the saved main provider snapshot and the actual pinned primary artifact;
primary figures do not imply a new provider financial snapshot.

Verified locally: 90 Python tests, 9 Node tests, both frontend syntax checks,
Python compilation and diff whitespace checks. Primary source pages were visually
inspected. Independent implementation review and exact-head CI precede merge.
The existing staged static-data workflow and live same-snapshot acceptance remain
the deployment path after approval; cloud plan updates are handled by the parent.

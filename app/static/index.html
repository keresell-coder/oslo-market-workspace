Oslo Stock web-app

A local-first workspace for watching Oslo-listed companies, combining RSI14 screener signals, source-labeled fundamentals, peer context, consensus data, and tracked events in one place.

How to read it

The Watchlist is the synthesis view. Each research tab contributes one compact Watchlist column so the most relevant signals are visible row-by-row.

Metrics used

Price, market cap, P/E, P/B, EV/EBITDA, dividend yield, target range, screener signal, peer context status, own-history context, and significant update status. Relative valuation requires peer, sector, own-history, and source-quality context.

Data sources

Yahoo Finance through yfinance, the published RSI14 screener dashboard, local consensus/source entries, local significant-event entries, and manually seeded peer groups.

Current limits

Peer groups use local curation status, sector benchmark components are explicit but still need reviewed KPI inputs, NewsWeb collection is manual, and target/rating methodology is not verified across providers.
